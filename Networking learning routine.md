#### **Day 1–3: Networking Device Basics**

**Topics:** Routing, switching, TCP/IP model, OSI layer.

1. **First Hour:**
    - Watch beginner-friendly videos:
        - _Networking Basics_ (FreeCodeCamp or NetworkChuck).
        - _TCP/IP & OSI Layers Explained_.
        - Explore Cisco Packet Tracer tutorials for hands-on basics.
2. **Second Hour:**
    - Read one chapter from "Computer Networking: Principles, Protocols, and Practice."
    - Use Cisco Networking Academy modules if available.
3. **Third Hour:**
    - Tasks:
        - Draw the OSI model layers and align protocols to each layer.
        - Capture live packets using Wireshark and identify protocols (e.g., ARP, HTTP).
    - **Addition:**
        - Set up a basic LAN with two PCs and one switch in Packet Tracer. Test connectivity.

---

#### **Day 4–6: Mid-Level Network Design**

**Topics:** Network design principles and topology.

1. **First Hour:**
    - Watch tutorials on **design principles**:
        - _How to Build a Scalable Network_ (NetworkChuck or Cisco tutorials).
    - Tools to explore: Draw.io or Lucidchart for manual network design.
2. **Second Hour:**
    - Study "Network Design Fundamentals" by Cisco Press or a similar guide.
    - Learn about addressing schemes (IPv4/IPv6 subnetting).
3. **Third Hour:**
    - Design and implement a network in Packet Tracer or GNS3:
        - Use multiple routers and VLANs.
        - Create and troubleshoot subnets.
    - **Addition:** Explore practical case studies on campus networks or SMB setups.

---

#### **Day 7–10: Protocols**

**Topics:** Deep dive into protocols (DNS, DHCP, HTTP/HTTPS, FTP, SMTP).

1. **First Hour:**
    - Watch tutorials:
        - _Protocol Basics_: DNS and DHCP examples using TryHackMe rooms or YouTube.
        - _Practical Applications_: Study how HTTP and HTTPS differ using SSL tools.
    - Bonus: Learn basics of ICMP (Ping and Traceroute).
2. **Second Hour:**
    - Explore protocol-related RFCs and guides.
    - Learn configuration syntax for protocols (e.g., bind9 for DNS in Linux).
3. **Third Hour:**
    - Practical implementation:
        - Deploy a DNS and DHCP server using Kali Linux or VirtualBox.
        - Create and capture HTTP/HTTPS requests with tools like cURL and Wireshark.
    - **Addition:** Set up a simple email server using Postfix or another tool.

---

#### **Day 11–15: Advanced Configuration**

**Topics:** Routers, switches, VLANs, dynamic routing protocols (e.g., OSPF, BGP).

1. **First Hour:**
    - Learn basics of CLI for routers and switches (Cisco, Mikrotik, Juniper).
    - Watch practical setup tutorials on VLANs and routing protocols.
2. **Second Hour:**
    - Configure VLANs and inter-VLAN routing on a Cisco switch.
    - Implement a routing protocol (e.g., configure OSPF on Cisco Packet Tracer).
3. **Third Hour:**
    - **Practical Task:**
        - Create a topology with dynamic routing in GNS3/Packet Tracer.
        - Configure basic NAT (Network Address Translation).
    - **Addition:** Learn to troubleshoot configurations using ping, traceroute, and debug commands.

---

#### **Day 16–20: Wireless Networks and Firewalls**

**Topics:** Access points, wireless network security, firewall setup.

1. **First Hour:**
    - Watch videos on **wireless networking basics**:
        - Setup examples for Cisco, TP-Link, or Ubiquiti access points.
    - Explore WPA2/WPA3 encryption and how wireless communication works.
2. **Second Hour:**
    - Study firewalls (pfSense, Cisco ASA):
        - Read setup guides and best practices.
    - Learn how to set firewall rules and monitor traffic.
3. **Third Hour:**
    - **Practical Task:**
        - Configure an access point and set up a secure wireless network (e.g., with WPA3).
        - Set up and test rules in pfSense or similar virtualized firewalls.
    - **Addition:** Perform a basic penetration test on your wireless network using tools like Aircrack-ng.

---

### **Daily Additions:**

1. **Case Studies:** Dedicate 15 minutes daily to studying real-world examples of network setups (e.g., ISP networks, enterprise environments).
2. **Challenge Tasks:**
    - Weekly: Solve one practical networking challenge on platforms like TryHackMe, HackTheBox, or Cisco DevNet.
3. **Network Simulation Labs:** At least twice weekly, build a new simulation in GNS3 or Packet Tracer to reinforce learning.
4. **Quiz and Review:** Spend the last 10 minutes of your session reviewing what you learned using flashcards or quizzes.
